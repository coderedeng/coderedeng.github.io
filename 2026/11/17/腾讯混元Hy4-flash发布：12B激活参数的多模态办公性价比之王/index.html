腾讯混元 Hy4 flash 发布：224B 总参数、12B 激活，多模态办公的"性价比之王"

|浏览量:

腾讯混元 Hy4 flash 发布：224B 总参数、12B 激活，多模态办公的"性价比之王"

背景：旗舰之后的"走量担当"

11 月 4 日，腾讯刚刚发布了开源旗舰模型 Hy4——它跻身世界领先开源模型行列，在 Artificial Analysis Intelligence Index 上位列中国模型第二、Agent Arena 榜单开源模型第一。而仅仅十二天后（11 月 16 日），腾讯混元团队又甩出了一张更务实的牌：Hy4 flash。

定位非常明确：不是再卷一次智能上限，而是做"迄今为止性价比最高的 Hy 模型"。官方推荐用它承担深度搜索、文档处理、PPT 生成、简单前端展示和 computer use 等日常高频任务，把长程软件工程这类硬骨头留给旗舰 Hy4。这几乎是所有大模型厂商正在走的路线——旗舰树品牌，flash 走量赚钱。

核心规格：224B 总参数，只激活 12B

Hy4 flash 的关键数字值得逐一看：

维度 数据
总参数 224B（含 64B Engram 参数）
激活参数 仅 12B
上下文 最高 1M tokens
模态 多模态输入
API 定价 输入 $0.070/M、输出 $0.281/M、缓存输入 $0.003/M

最激进的是激活参数比例：224B 总盘子里每次推理只点亮 12B，稀疏度超过 94%。作为参照，旗舰 Hy4 是 770B 总参、49B 激活——flash 版用约四分之一的总参数和不到四分之一的激活量，换来了官方口径"整体效果略优于 Hy4 Preview"的结果。

而其中 64B 是 Engram 条件记忆参数——这部分参数不走常规注意力计算路径，而是以"查表式"方式存储高频知识片段：当输入中出现某个触发模式时，对应的记忆槽位才被读取和激活，其余时间完全不占算力。这种设计把"记住事实"和"推理生成"解耦了——模型不再需要靠反复的注意力计算去"回忆"一个固定答案，直接查表即可。这就是为什么它敢把 KV cache 压缩到 Hy3 的 1/24、Hy4 的 1/6：混合注意力 + LatentMoE + Engram 三件套联手，把长上下文的显存开销砍到了极致。对 1M token 上下文场景来说，KV cache 每缩小一倍，能同时服务的并发请求就翻倍——这直接决定了推理成本的下限。

技术分析：从预训练到推理的全链路工程

官方罕见地披露了完整的工程链路，信息量不小：

预训练阶段，团队做了大量 scaling ladder（规模阶梯）实验来验证性能符合预期——这在闭源厂商里并不常见，说明 Engram 这类非标准架构需要反复校准缩放规律。

后训练阶段直接继承 Hy4 的架构与通用智能，强化学习把平均端到端任务输出 token 砍掉了一半。对办公场景来说，这意味着模型学会"少废话、多交付"——PPT 不再注水，文档不再车轱辘话。

评测体系是我最感兴趣的部分。团队自建了 WorkIndex 内部基准，覆盖 PPT 创建与编辑、文档编辑、表格修复、音视频处理、视觉理解等 WorkBuddy 真实办公任务，配合人工评审，考核的是交付质量、单轮输出长度和任务周转时间，而不是脱离日常工作的公开跑分。外部则用 DeepSWE、ProgramBench、Terminal-Bench 4.0、APEX-Agents、AutomationBench、HLE、OSWorld 2.1 七个 Agent 评测集交叉验证。

推理侧，megakernel 优化 + 4-bit 量化 + DFly 技术组合拳，把解码速度推到了 150 tokens/s 以上。配合极低的激活参数，单任务成本被压到 Hy4 Preview（770B 总参/49B 激活）的 1/13、Hy4 的 1/20、DeepSeek-V4.1-Flash-1017 峰值时段的 1/8。

盲测数据：逼近 Claude Haiku 5.5 的满意度

最有说服力的不是跑分，而是腾讯自己人的盲测：85 名内部 WorkBuddy 用户、27 个类别、259 个真实任务的双盲对比中，Hy4 flash 的用户满意度接近 Claude Haiku 5.5，同时是所有参评模型中单任务成本最低、完成速度最快的一个。

这个结果值得玩味——它暗示在"日常办公"这个细分战场上，模型能力的边际收益已经很小，响应速度 + 输出克制 + 价格才是决定体验的三驾马车。

竞争格局：flash 档位的价格战升级

把 Hy4 flash 放进当前的 flash 档位坐标系里看，它的进攻性相当明显。DeepSeek-V4.1-Flash-1017 是过去几个月小模型市场的价格锚点——腾讯给出的数据是单任务成本只有前者的 1/8（Max 档峰值时段口径）。Claude Haiku 5.5 在 10 月以"90% 降价 + 可调思考档位"守住了小模型市场，而 Hy4 flash 的盲测满意度已经逼近它，价格却低一个量级。

更值得注意的是架构层面的差异化。各家 flash 模型基本都在"缩小旗舰"这条路上内卷——参数砍一半、蒸馏一下、量化部署。Hy4 flash 则换了条路：不追求和旗舰同构，而是用 Engram 条件记忆 + LatentMoE 重新设计计算路径，把"知识存储"从算力密集型的注意力计算中剥离出来。如果这条路线被验证有效，它可能成为下一代小模型架构的参考模板——毕竟开源承诺意味着所有竞争者都能直接拆解学习。

影响与展望

Hy4 flash 已全量上线腾讯云 TokenHub、WorkBuddy、元宝、企业微信、QQ、ima 和 Marvis，OpenRouter 接入在即；11 月 30 日前 WorkBuddy 免费使用，TokenHub 五折。更关键的是，腾讯明确表态将开源 Hy4 flash 并持续高频迭代。

如果兑现，2026 年下半年的开源小模型战场将迎来一位重量级选手：1M 上下文 + 多模态 + 150 tok/s 解码速度 + 办公场景深度优化，这套组合拳直接对标 DeepSeek-V4.1-Flash 和各家 flash 档位模型。大模型竞争的下半场，胜负手正在从"谁更聪明"滑向"谁更便宜、更快、更能干活"——腾讯这一手，显然是冲着后者去的。
