DeepSeek发布Harness：一切皆插件的开源Agent框架

发表于2026-09-03|更新于2026-09-04|Tech前沿
|浏览量:

一、一个”懒到极致”的 Agent 框架横空出世

2026年8月，DeepSeek 开源了 Harness（deepseek-harness，简称 dsh）——一个以”一切皆插件”（Everything is a Plugin）为核心理念的开源 Agent 开发框架。发布不到三周，GitHub Star 迅速突破 20.9万，一周内净增约 1.3万，成为继 Claude Code、Codex 之后又一款现象级开源编程工具。

与市面上大多数”模型 + 第三方外壳”的组合不同，DeepSeek Harness 的野心在于重新定义 Agent 的构建方式：模型不再是框架的核心，而只是可被任意替换的一个插件。开发者可以在不改动一行代码的前提下，通过配置文件自由切换模型、工具、技能、会话管理、沙箱、存储乃至用户界面。

二、核心理念：一切皆插件

DeepSeek Harness 的设计哲学可以概括为一句话——**”Everything is a Plugin”**。在这个框架里，Agent 所需的全部能力都被抽象为插件：

  • 模型（Model）：任何兼容 OpenAI 接口的端点都可以作为模型插件接入
  • 工具（Tool）：文件读写、代码执行、网络请求等外部能力
  • 技能（Skill）：可复用的任务模板与工作流
  • 会话（Session）：对话状态与上下文的持久化
  • 沙箱（SandBox）：隔离的代码执行环境
  • 存储（Storage）：数据与记忆的存取
  • 循环（Loop）：Agent 的推理迭代逻辑
  • 调度（Schedule）：定时任务与后台作业
  • UI：命令行、Web、IDE 插件等交互界面

这种设计带来的最大好处是解耦。传统 Agent 框架往往将模型与运行时深度绑定，更换底层模型或调整行为模式需要大量改造。而在 DeepSeek Harness 中，”换模型”只是一行配置的改动——配置指向 OpenAI 就用 OpenAI，指向本地部署的 Qwen 就用 Qwen，框架本身毫不知情。

三、Cordis：支撑”一切皆插件”的元框架

DeepSeek Harness 之所以能实现如此彻底的插件化，离不开其底层框架 Cordis。Cordis 是一个名为”时空组合性“（Spatiotemporal Composability）的元框架，最初源自 Koishi 聊天机器人框架的架构设计，后被 DeepSeek 抽取并形式化为独立项目。

在 Cordis 的理论体系中，程序的可组合性由两个正交维度构成：

  1. 可回滚效应（Revertible Effects）：控制操作的执行与撤销，使 Agent 的行为具备事务特性
  2. 反应式协同效应（Reactive Coeffects）：管理环境对计算的反馈，让插件之间能够实时协作

这两个维度的组合，使得 Cordis 能够将模型、工具、会话等能力组织成一棵可配置、可插拔的”插件树”。每个节点既能独立运行，又能通过 Cordis 的事件机制与其他节点协同工作。DeepSeek 为此发表了长达 88 页的论文《A Programming Paradigm for Spatiotemporal Composability》，系统阐述了这一编程范式。

四、技术架构与核心特性

1. 配置驱动的插件树

开发者通过一个中心化的配置文件定义 Agent 的行为。配置中声明需要哪些插件、如何组合，运行时由 Cordis 负责组装成完整的执行链路。这种”声明式”的构建方式大幅降低了使用门槛——无需编写大量胶水代码，即可搭建出功能完备的 Agent。

2. 模型无关性

由于模型只是众多插件中的一种，DeepSeek Harness 对具体模型零依赖。无论是 DeepSeek 自家的模型、OpenAI 的 GPT 系列，还是本地部署的开源模型，都可以通过统一的 OpenAI 兼容接口接入。这对注重数据隐私或成本控制的团队尤为重要。

3. 可扩展的执行环境

框架内置了沙箱机制，确保 Agent 执行代码时的安全性。配合可插拔的存储与调度插件，开发者可以灵活构建从简单问答到复杂自动化任务的各类应用。

五、行业意义与展望

DeepSeek Harness 的出现标志着开源 Agent 生态进入新阶段：

  • 降低构建门槛：插件化 + 配置驱动让非资深开发者也能搭建专业级 Agent
  • 打破供应商锁定：模型无关设计使团队摆脱对单一厂商的依赖
  • 推动标准化：OpenAI 兼容接口成为事实标准，促进了工具生态的互联互通

当然，作为一个新兴框架，DeepSeek Harness 在成熟度、社区支持、文档完善等方面仍有成长空间。但随着 20.9万 Star 背后的庞大社区力量，它有望成为继 LangChain、AutoGPT 之后又一款定义行业的开源项目。

对于 AI 开发者而言，DeepSeek Harness 提出的”一切皆插件”理念值得深入关注——它不仅是一种技术架构的选择，更代表了 Agent 开发范式的演进方向。
